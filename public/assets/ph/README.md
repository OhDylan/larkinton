# Poly Haven assets

Models and textures in this folder are from [Poly Haven](https://polyhaven.com) and are licensed **CC0** (public domain).
They were downloaded at 1k resolution, then downsized to 512 px; the textures were recoloured to the design palette.

Models: tea_set_01, ceramic_vase_01–04, antique_ceramic_vase_01, wooden_bowl_01, pachira_aquatica_01, potted_plant_02, dry_branches_medium_01, modern_arm_chair_01, chinese_tea_table, chinese_stool, WoodenTable_02, hanging_picture_frame_03, planter_pot_clay, potted_plant_04.
Textures: walnut_veneer, smoked_walnut_veneer, teak_veneer, plaster_grey_04, rough_linen (as cream / linen / sand / taupe), brown_leather, plank_flooring_02, smooth_concrete_floor, poly_wool_herringbone (as jute).
