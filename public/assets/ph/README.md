# 3D assets

Everything here is pre-optimised for the web with gltf-transform: single-file GLBs with
meshopt-compressed geometry, WebP textures at 512 px (sofa 1024 px), unused variants pruned.

## Poly Haven — CC0 (public domain), https://polyhaven.com
Models (glb/): ceramic_vase_01–04, antique_ceramic_vase_01, wooden_bowl_01, pachira_aquatica_01
(variant d only), potted_plant_02, potted_plant_04, dry_branches_medium_01 (branch a only), planter_pot_clay.
Textures (tex/, recoloured to the palette): walnut_veneer, smoked_walnut_veneer, teak_veneer,
plaster_grey_04, rough_linen (as cream / linen / sand / taupe), brown_leather, plank_flooring_02,
smooth_concrete_floor, poly_wool_herringbone (as jute).

licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Credited on screen.
